Rnhanced version of pfquest for octowow

Based on original pfquest, but:
- shows markers for quest items that are dropped from mobs and objects
- has up-to-date quest data for octowow
- repeatable and event quests have different colors now and separate options to show them
- there is a new "/db hidden" command to see manually hidden quests list 
and "/db hidden clean" to clean all manually hidden quests list
